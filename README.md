## Local Development
### Prerequisites
* Node.js (v20 recommended)
* npm

### Installation
1.  **Install dependencies:**
    ```bash
    npm install
    ```

2. **Build the app:**
   ```bash
   npm run build
   ```
   
3. **Test the app:**:
   ```bash
   npm run test
   ```
   
4. **Start the app:**:
   ```bash
   npm run dev
   ```
